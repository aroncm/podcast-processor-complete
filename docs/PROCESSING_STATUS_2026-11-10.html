Where things stand. PodThreads is caught up on every episode released in the last 60 days except one, the John Hoctor episode of AdTechGod Pod released today, which tonight's run will process.

What changed today. The nightly run now takes the newest episodes first across all podcasts, and only from the last 60 days.

Decision. The back catalog of 715 older episodes stays unprocessed for now. Processing all of it would cost about $410.

How the nightly run works now

Every night at 7:00 pm Eastern (8:00 pm in summer), the processor does the following:

  1. It looks at all seven active podcast feeds and finds every episode that has not been processed yet.
  2. It keeps only episodes released in the last 60 days.
  3. It sorts them by release date, newest first, no matter which podcast they come from.
  4. It processes the top 4.

So a new release always goes first, whichever podcast it belongs to. Older episodes from the last 60 days get any slots left over. Anything older than 60 days runs only when someone picks its dates on the Episode Processing screen in Admin.

If OpenAI runs out of credits, the run stops, says so at the top of every Admin tab, and picks up again on the next night once the balance is topped up.

Why it changed

Before today, the run went through the podcasts in a fixed order: Marketecture, Open Market, AdTechGod Pod, The Aperiam Podcast, The FPC Podcast, The AI Edge Podcast, then Adtech Adtalk. In each podcast it took any of the 10 newest episodes that had not been processed, up to 2 per podcast, until it had 4.

Nothing limited how old those episodes could be. On the night of November 9, for example, the run processed one new episode and three older ones:

What a backfill would cost

The 72 episodes processed since October 15 cost an average of $0.57 each (median $0.56, lowest $0.25, highest $1.01). About $0.24 of that is transcription and $0.34 is the AI work of picking, checking and placing takes. The average episode ran 39 minutes.

Decision and next steps

  • Hold the full backfill for now (Craig, November 10).
  • The nightly run keeps PodThreads current on new releases with no action needed.
  • To process older episodes later, open Admin, then Episode Processing, choose Custom Range with the dates wanted, and run it. Doing one podcast or one year at a time keeps the review queue manageable.
